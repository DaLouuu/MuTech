# Manuscript Tables & Verification Manifests

Tables and evidence manifests for the SLR manuscript (Sections 2.1–4.5, Tables 4–11), incorporating positive lexical domain/modality tagging, recovered database provenance, and quality appraisal scores.

| File | Description |
|---|---|
| [`domain_modality_tags.csv`](domain_modality_tags.csv) / [`_v3.csv`](domain_modality_tags_v3.csv) | All 365 papers with word-boundary domain (`Instrumental`: 151, `Unclassified`: 142, `Solo Singing`: 62, `Ensemble (vocal)`: 10) and modality (`Audio`: 178, `Symbolic`: 71, `Multimodal`: 64, `Unclassified`: 52) classifications with positive keyword evidence. Source for manuscript Tables 6–7. |
| [`numbers_manifest.txt`](numbers_manifest.txt) / [`_v3.txt`](numbers_manifest_v3.txt) | Authoritative statistical manifest containing exact recomputed numbers, cross-tabulations (year × domain, domain × modality, cluster × domain), and descriptive quality rubric distributions. Use this to verify any claim or number in the manuscript. |
| [`corpus_provenance.csv`](corpus_provenance.csv) | Recovered publication venue and source database for all 365 studies (**Scopus: 316 [86.6%]**, **IEEE: 49 [13.4%]**). Resolves the Rayyan provenance overwrite. Source for Section 2.1. |
| [`quality_scores.csv`](quality_scores.csv) / [`_v2.csv`](quality_scores_v2.csv) | Descriptive quality appraisal scores across 9 criteria (adapted from Borbon & Ebardo, 2025). Descriptive only — no study was excluded by score. Source for manuscript Tables 4–5. |
| [`challenge_evidence.csv`](challenge_evidence.csv) | Paper-level evidence behind Table 11 (challenges and algorithmic limitations). |
| [`validation_sample_30.xlsx`](validation_sample_30.xlsx) | Stratified sample for domain/modality tagging validation audit trail. |
| [`quality_spotcheck_15.xlsx`](quality_spotcheck_15.xlsx) | Stratified sample for quality scoring validation audit trail. |
