## What moved, and what to change in the manuscript

### Provenance — new, previously unreportable

`Source Database` read `Rayyan` for all 365 rows; the Rayyan round trip overwrote it. Joined
back to `merged_deduplicated.csv` on normalised title, with a DOI fallback: **365/365
recovered — Scopus 316 (86.6%), IEEE 49 (13.4%)**. Section 2.1 can now state the split.

`Publication Venue` recovers for the 49 IEEE papers only. The Scopus rows held the literal
string `"Scopus"` — the which-database flag copied in as if it were a journal name — which
this script nulls rather than propagates. Real Scopus venues need a re-pull or a Crossref
DOI lookup.

### 3.1.2 Domain distribution — the headline changes

The v2 tagger had no positive rule for "General MIR"; it was the `else` branch, and all 170
rows carried empty evidence. Renamed `Unclassified` and given an explicit `domain_rule`
column. Matching is now word-boundary, and ML-ensemble phrasing is stripped before any
musical-ensemble term is tested.

| Label | v2 (in the drafts) | v3 (corrected) |
|---|---|---|
| Instrumental | 133 (36.4%) | **151 (41.4%)** |
| General MIR → **Unclassified** | 170 (46.6%) | **142 (38.9%)** |
| Solo Singing | 52 (14.2%) | **62 (17.0%)** |
| Ensemble → **Ensemble (vocal)** | 10 (2.7%) | **10 (2.7%)** |

28 papers move out of the default bucket on positive evidence (`instrumental performance`,
`xylophone`, `drums`, `vocal technique`, `singing styles`, …). **Instrumental is now the
largest domain**, which retires the "General MIR dominates" sentence entirely — that claim
was never a finding, it was the residual.

Table 6 (year × domain) and Table 7 (domain × modality) both need replacing from
`numbers_manifest_v3.txt`.

### 3.1.3 Modality distribution — the 71% audio figure does not survive

`Audio` was also the `else` branch: 259 rows, zero evidence. Testing positive audio
indicators (spectrogram, waveform, STFT, MFCC, CQT, acoustic signal, …) splits it:

| Label | v2 | v3 |
|---|---|---|
| Audio | 259 (71.0%) | **180 (49.3%) evidenced** |
| — | — | **72 (19.7%) Unspecified** |
| Symbolic | 71 (19.5%) | **77 (21.1%)** |
| Multimodal | 35 (9.6%) | **36 (9.9%)** |

"Audio-only processing accounts for 71.0%" becomes "49.3% carry an explicit audio
indicator; a further 19.7% specify no modality at all." Table 10's negative result
(evaluation practice is modality-independent) should be re-derived against the corrected
variable or explicitly caveated — one fifth of the corpus has no modality signal.

### Gap 1 — "ensemble is a 2.7% niche" was a definition

The v2 `Ensemble` domain matched vocal terms only (`choral`, `choir`, `a cappella`, `satb`,
…), so nine orchestral papers were routed to `Instrumental`. A separate orthogonal
`ensemble_scope` axis now records multi-performer context without disturbing the domain
axis:

| Ensemble scope | Papers |
|---|---|
| Vocal ensemble | 8 |
| Instrumental ensemble | 13 |
| Mixed / both | 2 |
| Not indicated | 342 |
| **Any multi-performer indication** | **23 (6.3%)** |

So the honest statement is: *choral/vocal-ensemble* processing is a 2.7% niche; ensemble
processing broadly is 6.3%. Gap 1 and reversal #2 in `WHAT_CHANGED_AND_WHY.md` both need
this qualifier, and 2.3 should state the operational definition.

### 4.4 trend (2) — 6.2× is a window artifact

2020–2022 is three years and 123 papers; 2023–2026 is four years and 242 papers, with 2026
partial. Music Education & Performance Assessment:

| Framing | Value |
|---|---|
| Raw ratio (as published) | 6.18× |
| Per-year rate | **4.64×** |
| Share-of-corpus normalised | **3.16×** |

The relative ordering across clusters survives all three framings, so the finding holds —
only the multiplier is wrong. Full table for all seven clusters in the manifest. Table 9's
era columns carry the same asymmetry.

### Tables 4–5 — quality scoring

- Bin labels `0–20 / 20–25 / 25–30 / …` overlap at every boundary. They compute correctly
  only because nine criteria scored 1/3/5 can never sum to an even number — `quality_total`
  takes 13 attainable odd values, 17 to 41. Replace with `17–20 / 21–25 / 26–30 / …`
  (counts are unchanged: 3 / 43 / 99 / 167 / 50 / 3).
- `q_alignment` scores 5 for **345 of 365** papers. It discriminates almost nothing while
  contributing 11% of the maximum, inflating every total.
  `quality_total_excl_alignment` (max 40) is added alongside: mean 26.18, median 26,
  range 12–36.
- `q_reproducibility` (mean 2.11, 47.4% at the floor) cannot distinguish "no code released"
  from "code released, not mentioned in the abstract." Gap 3 should be phrased as a finding
  about abstract reporting practice, not about the field's actual reproducibility.

## Three false positives found and removed during this rebuild

Documented because two of them also affect the v2 tags that the current drafts use:

| Term | Why it was dropped |
|---|---|
| `chorus` | Song-structure label ("verse or chorus"). **The v2 tagger used it** and mis-tagged *Classification of Music Structural Functions using Deep Learning* as an Ensemble paper. |
| `duet` | DUET — Degenerate Unmixing Estimation Technique, a blind source separation algorithm named alongside FastICA and NMF. |
| `vibrato` | An expressive element of violin playing as much as of singing; it mis-tagged *Violinist identification based on vibrato features*. |

## What this does not fix

The ten defects at the end of `numbers_manifest_v3.txt`. Four matter most:

1. **Authors.** Scopus `creator` is the first author only, so all 365 records carry one
   name. Every `et al.` in Parts 5–6 and 18 of 99 citations in `challenge_evidence.csv`
   (initials parsed as surnames — `[X., 2023]`, `[M., 2026]`) depend on it. Needs a Scopus
   re-pull with `author_names` or a Crossref DOI lookup.
2. **Silhouette 0.0389.** The clusters are interpretable but weakly separated. Cluster-level
   claims are exploratory; the prose in 3.3 and Section 4 currently is not.
3. **Phase 5 modularity is not independent.** It is computed on a kNN graph built from the
   same TF-IDF cosine geometry K-Means partitions. Louvain finds 10 communities, not 7.
4. **`validation_sample_30.xlsx` is an empty template** — header plus 23 blank rows. The
   "validated against a manually reviewed sample" claim in 2.3 and the Table 6 note has no
   receipt.
