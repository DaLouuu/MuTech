# GitHub Pages Live Social Network Analysis (SNA) Dashboard

This folder contains the compiled, standalone interactive Social Network Analysis (SNA) topic co-occurrence network generated from the 365 peer-reviewed studies in Phase 5 of the SLR.

- **Live URL:** [https://dalouuu.github.io/MuTech/](https://dalouuu.github.io/MuTech/)
- **Source Pipeline:** Generated by [`slr/src/pipeline_engine.py`](../slr/src/pipeline_engine.py) (Phase 5) using NetworkX, with exports saved to [`slr/outputs/network/`](../slr/outputs/network/).
- **Published Asset:** [`docs/index.html`](index.html)
